## ✨ Interactive Elements

### Dismiss Button:
```
Normal State:
  ┌─────┐
  │  ✕  │  ← Gray X in top-right corner
  └─────┘

Hover State:
  ┌─────┐
  │  ✕  │  ← White background appears
  └─────┘
    Smooth transition 200ms

Click:
  Banner fades out (300ms)
  Slides up slightly
  Removed from DOM
```

### Responsive Behavior:
```
Desktop (>768px):
  - Horizontal layout
  - Icon on left
  - Content in middle
  - Emoji on right
  - Larger text sizes

Tablet (768px-1024px):
  - Slightly reduced padding
  - Smaller icons
  - Content wraps if needed

Mobile (<768px):
  - Vertical stack
  - Icon at top
  - Content below
  - Emoji at bottom
  - Smaller text sizes
```

## 🎯 States & Conditions

### When Banner Shows:

#### Students:
```
✅ SHOW if:
   - Promoted within last 4 weeks (28 days)
   - is_reverted = false
   - User is logged in
   - Not previously dismissed in this session

❌ DON'T SHOW if:
   - More than 4 weeks since promotion
   - Promotion was reverted
   - User dismissed it
   - No promotion found
```

#### Class Teachers:
```
✅ SHOW if:
   - Teacher has class_id assigned
   - User is logged in
   - Not previously dismissed

OPTIONAL INFO:
   - If new students promoted (show count)
   - If no new students (skip that section)
```

#### Regular Teachers:
```
✅ SHOW if:
   - Teacher has no class_id
   - User is logged in
   - Not previously dismissed

SIMPLE MESSAGE:
   - Just welcome to new session
   - No class-specific details
```
