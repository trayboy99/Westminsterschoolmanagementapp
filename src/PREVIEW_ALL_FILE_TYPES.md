# 🎯 ALL FILE TYPES - Preview Support Guide

## 📋 Quick Answer

**Question:** "What file types can be previewed?"

**Answer:**

### ✅ CAN PREVIEW (In Browser):
1. **PDF** - Full document viewer
2. **Images** - JPG, PNG, GIF, WebP, SVG, BMP
3. **Videos** - MP4, WebM, OGG
4. **Audio** - MP3, WAV, OGG, M4A
5. **Text** - TXT, MD, JSON, XML, CSV, LOG

### ⬇️ DOWNLOAD TO VIEW:
1. **Word** - DOC, DOCX
2. **Excel** - XLS, XLSX
3. **PowerPoint** - PPT, PPTX
4. **Archives** - ZIP, RAR, 7Z
5. **Other** - Any unsupported format

## 🎓 For Teachers: Best File Formats to Upload

### 📚 Class Notes & Documents
**✅ BEST:** PDF
- Students can preview immediately
- Works on all devices
- Cannot be edited

**❌ AVOID:** DOCX
- Students must download first
- Extra step to view
- Consider converting to PDF

### 🖼️ Diagrams & Images
**✅ BEST:** JPG or PNG
- Instant preview
- Works perfectly
- Good quality

**✅ ALSO GOOD:** SVG
- Perfect for diagrams
- Scalable graphics

### 🎥 Video Lessons
**✅ BEST:** MP4
- Universal support
- Plays in browser
- No download needed

**❌ AVOID:** AVI, MOV
- Not supported
- Must download
- Convert to MP4 instead

### 🎵 Audio Lessons
**✅ BEST:** MP3
- Universal support
- Plays in browser
- Good compression

**✅ ALSO GOOD:** M4A
- Modern format
- Good quality

### 📊 Data & Spreadsheets
**✅ BEST:** CSV
- Can preview as text
- Works everywhere

**❌ AVOID:** XLSX
- Must download
- No preview
- Export to CSV or PDF instead

### 📽️ Presentations
**✅ BEST:** PDF (exported from PowerPoint)
- Students can view slides
- No download needed
- Preserves formatting

**❌ AVOID:** PPTX
- Must download
- Cannot preview
- Export to PDF instead

## 🔄 How to Convert Files

### Word → PDF (For Preview)
**Method 1: Microsoft Word**
1. Open your document
2. File → Save As
3. Format: PDF
4. Save and upload ✅

**Method 2: Google Docs**
1. Upload to Google Drive
2. Open in Google Docs
3. File → Download → PDF
4. Upload to school system ✅

### PowerPoint → PDF (For Preview)
**Method 1: PowerPoint**
1. Open presentation
2. File → Export → Create PDF
3. Save and upload ✅

**Method 2: Google Slides**
1. Upload to Google Drive
2. Open in Google Slides
3. File → Download → PDF
4. Upload to school system ✅

### Excel → CSV (For Preview)
1. Open spreadsheet
2. File → Save As
3. Format: CSV
4. Upload ✅
