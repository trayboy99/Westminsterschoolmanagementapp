## 🎯 Grouping Logic

### How Questions are Grouped:

```
BEFORE (Individual Questions):
├── Question 1: Mathematics, SS1, Algebra, ...
├── Question 2: Mathematics, SS1, Geometry, ...
├── Question 3: Mathematics, SS1, Trigonometry, ...
├── Question 4: English, SS2, Grammar, ...
├── Question 5: English, SS2, Comprehension, ...
└── ... (and so on)

AFTER (Grouped Question Banks):
├── 📁 Mathematics - SS1 - 2025/2026 - First Term (15 questions)
│   ├── Question 1: Algebra
│   ├── Question 2: Geometry
│   ├── Question 3: Trigonometry
│   └── ... (12 more)
│
├── 📁 English - SS2 - 2025/2026 - First Term (12 questions)
│   ├── Question 4: Grammar
│   ├── Question 5: Comprehension
│   └── ... (10 more)
│
└── 📁 Physics - SS1 - 2025/2026 - Second Term (8 questions)
    └── ...
```

### Grouping Key:
```
Subject + Class + Session + Term = One Question Bank Card
```

## ✨ Key Features Summary

### 1. **Organized by Academic Structure**
   - Session: 2024/2025, 2025/2026, etc.
   - Term: First Term, Second Term, Third Term
   - Subject: Mathematics, English, Physics, etc.
   - Class: SS1, SS2, SS3, JSS1, etc.

### 2. **Quick Stats Per Bank**
   - Total questions count
   - Total marks
   - Published vs Draft breakdown

### 3. **Easy Navigation**
   - Click card to view all questions
   - Filter by any combination
   - Search across all fields

### 4. **Mobile Optimized**
   - Touch-friendly cards
   - Responsive grid
   - Scrollable modals
   - Readable on small screens

## 🔄 User Workflow

```
1. Teacher Login
   ↓
2. Navigate to CBT Questions
   ↓
3. See Question Banks (Grouped Cards)
   ↓
4. Either:
   a) Click "View Questions" → See all questions in that bank
   b) Click "Create Question" → Add new question with Session/Term
   ↓
5. Questions auto-grouped by Subject/Class/Session/Term
   ↓
6. Cards update automatically with new question counts
```
