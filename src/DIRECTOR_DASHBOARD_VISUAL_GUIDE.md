## Color Legend

### Icons:
- 👥 = Users (Teachers) - **Blue**
- 🎓 = GraduationCap (Students) - **Green**
- 📚 = BookOpen (Classes) - **Purple**
- ✅ = ClipboardCheck (Compliance) - **Orange**
- 📅 = Calendar (Timetable) - **Blue**
- 📄 = FileText (Results) - **Blue**
- 💰 = DollarSign (Finance) - **Green**
- ⚙️ = Settings - **Gray**

### UI States:
- **Active:** Blue-600 background
- **Hover:** Slate-800 background
- **Default:** Transparent
- **Border:** Slate-700
