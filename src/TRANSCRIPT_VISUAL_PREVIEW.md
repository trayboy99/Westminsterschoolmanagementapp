## 🎨 Visual Features

### **Color Coding**
- 🟢 **Grade A** (75-100) - Green badges
- 🔵 **Grade B** (65-74) - Blue badges  
- 🟡 **Grade C** (55-64) - Yellow badges
- 🟠 **Grade D** (45-54) - Orange badges
- 🔴 **Grade F** (0-44) - Red badges

### **Sections**
1. **Header** - School name and logo
2. **Student Info** - Light gray background box
3. **Academic Records** - Tables for each session
4. **Summary** - Blue gradient highlight
5. **Grading Scale** - Reference guide
6. **Certification** - Official signatures

### **Interactive Elements**
- ✅ Print button - Opens print dialog
- ✅ Download button - Saves as PDF
- ✅ New Search - Returns to login

## 📏 Responsive Behavior

### **Mobile (< 768px)**
- Stacked layout

- 2-column student info
