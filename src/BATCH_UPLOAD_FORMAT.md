# 📝 CBT Batch Upload Format Guide

## Upload Multiple Questions at Once!

You can now upload 40, 50, or even 100 questions in a single Word document!

## Format Example

```
1. Which of the following is a noun?
A. Run
B. Happy
C. Book *
D. Quickly

2. What is the capital of Nigeria?
A. Lagos
B. Abuja *
C. Kano
D. Port Harcourt

3. Who wrote "Things Fall Apart"?
A. Wole Soyinka
B. Chinua Achebe *
C. Chimamanda Adichie
D. Ben Okri

4. What is 5 + 3?
A. 6
B. 7
C. 8 *
D. 9
```

## Important Rules

1. **Number your questions**: Start with `1.`, `2.`, `3.`, etc.
2. **Use asterisk (*)** to mark the correct answer
3. **Options must start with letters**: A., B., C., D., etc.
4. **One blank line** between questions is recommended (optional)

## Before Uploading

**IMPORTANT:** Select these fields BEFORE uploading your Word document:
- ✅ Subject (e.g., English, Mathematics)
- ✅ Class (e.g., JSS 1, SS 3)
- ✅ Session (e.g., 2023/2024)
- ✅ Term (e.g., First Term)

## What Happens

1. System detects all questions in your document
2. Shows a confirmation: "Found 40 questions! Create all 40 questions?"
3. Creates all questions automatically with progress indicator
4. Shows success: "✅ Created: 40 questions"

## Tips

- Questions can be on the same line or separate lines
- You can have spaces or no spaces - system handles both
- Works with concatenated options: `A. RunB. HappyC. Book *D. Quickly`
- Automatically detects and separates all questions

## Example with No Spacing

```
1. What is a verb?A. BookB. Run *C. HappyD. Tall
2. What is 2+2?A. 3B. 4 *C. 5D. 6
```

Both formats work perfectly! 🎉
