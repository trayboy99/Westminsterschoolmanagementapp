# 📁 File Preview - Supported File Types

## ✅ Currently Supported File Types

### 📄 Documents

| File Type | Extensions | Preview Type | Notes |
|-----------|-----------|--------------|-------|
| **PDF** | `.pdf` | ✅ In-Browser Viewer | Full preview with scrolling |
| **Word** | `.doc`, `.docx` | ⬇️ Download Prompt | Cannot preview in browser - shows download button |

### 🖼️ Images (NEW!)

| File Type | Extensions | Preview Type | Notes |
|-----------|-----------|--------------|-------|
| **JPEG** | `.jpg`, `.jpeg` | ✅ Full Preview | Zoom and pan support |
| **PNG** | `.png` | ✅ Full Preview | Transparent backgrounds supported |
| **GIF** | `.gif` | ✅ Full Preview | Animated GIFs play automatically |
| **WebP** | `.webp` | ✅ Full Preview | Modern image format |
| **SVG** | `.svg` | ✅ Full Preview | Vector graphics |
| **BMP** | `.bmp` | ✅ Full Preview | Bitmap images |

### 🎥 Videos (NEW!)

| File Type | Extensions | Preview Type | Notes |
|-----------|-----------|--------------|-------|
| **MP4** | `.mp4` | ✅ Video Player | Full playback controls |
| **WebM** | `.webm` | ✅ Video Player | Modern video format |

### 🎵 Audio (NEW!)

| File Type | Extensions | Preview Type | Notes |
|-----------|-----------|--------------|-------|
| **MP3** | `.mp3` | ✅ Audio Player | Full playback controls |
| **WAV** | `.wav` | ✅ Audio Player | Uncompressed audio |
| **OGG** | `.ogg` | ✅ Audio Player | Open format |

### 📝 Text Files (NEW!)

| File Type | Extensions | Preview Type | Notes |
|-----------|-----------|--------------|-------|
| **Plain Text** | `.txt` | ✅ Text Viewer | Full text content |
| **Markdown** | `.md` | ✅ Text Viewer | Raw markdown |
| **JSON** | `.json` | ✅ Text Viewer | Code formatting |
| **XML** | `.xml` | ✅ Text Viewer | Code formatting |
| **CSV** | `.csv` | ✅ Text Viewer | Comma-separated values |
| **Log** | `.log` | ✅ Text Viewer | Log files |

### 📊 Office Files (Download Only)

| File Type | Extensions | Preview Type | Notes |
|-----------|-----------|--------------|-------|
| **PowerPoint** | `.ppt`, `.pptx` | ⬇️ Download Prompt | Cannot preview - download to view |
| **Excel** | `.xls`, `.xlsx` | ⬇️ Download Prompt | Cannot preview - download to view |

### ❌ Other Files

| File Type | Preview Type | Notes |
|-----------|--------------|-------|
| **ZIP, RAR, 7Z** | ⬇️ Download Only | Archive files - download to extract |
| **EXE, DLL** | ⬇️ Download Only | Executable files - download warning |
| **Other** | ⬇️ Download Prompt | Shows friendly message with download button |

## 💡 Best Practices for Teachers

### For Best Preview Experience:

**✅ DO Upload:**
- PDF for documents (converts Word → PDF)
- JPG/PNG for images
- MP4 for videos
- MP3 for audio
- TXT for simple notes

**❌ AVOID (Download Only):**
- DOCX files (convert to PDF instead)
- PPTX files (export to PDF)
- XLSX files (export to PDF or CSV)
- ZIP files (upload files individually)

### Converting Files for Preview

**Word to PDF:**
1. Open document in Microsoft Word
2. File → Save As
3. Choose PDF format
4. Upload PDF (students can preview!)

**PowerPoint to PDF:**
1. Open presentation in PowerPoint
2. File → Save As
3. Choose PDF format
4. Upload PDF (students can view slides!)

**Excel to CSV:**
1. Open spreadsheet in Excel
2. File → Save As
3. Choose CSV format
4. Upload CSV (students can preview data!)
