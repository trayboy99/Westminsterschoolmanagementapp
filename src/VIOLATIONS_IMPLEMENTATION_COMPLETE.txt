### 3. Backend API Endpoint
✅ GET /cbt/violations/:attemptId
✅ Returns all violations for a specific exam attempt
✅ Includes screenshot URLs from Supabase Storage
✅ Ordered by timestamp (newest first)
✅ Requires authentication

### 4. Data Flow:
1. Admin clicks on violations button (Camera icon + count)
2. Frontend calls `/cbt/violations/{attemptId}`
3. Server fetches all violation records from `cbt_violation_logs`
4. Returns violations with screenshot URLs
5. Modal displays violations with embedded screenshots
6. Admin can click to view full-size screenshots

### 5. Screenshot Storage Structure:
- Bucket: `make-1ddd013a-cbt-violations`
- Path: `{attemptId}/{violationType}-{timestamp}.jpg`
- Access: Private with signed URLs (valid 1 year)
- Evidence preserved for admin/teacher review
