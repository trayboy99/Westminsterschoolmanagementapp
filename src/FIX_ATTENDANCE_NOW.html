🔧 Fix Attendance ON CONFLICT Error

Quick 3-step fix for your School Management System

❌ Error: there is no unique or exclusion constraint matching the ON CONFLICT specification
⚠️ Problem: Your attendance table is missing a UNIQUE constraint on (student_id, date). The backend needs this to prevent duplicate records.
1 Open Supabase SQL Editor

Go to your Supabase Dashboard → Click "SQL Editor" (left sidebar) → Click "New Query"

2 Copy and Paste This SQL 
-- Remove any existing duplicates
DELETE FROM attendance a
USING attendance b
WHERE a.student_id = b.student_id
  AND a.date = b.date
  AND a.id < b.id;

-- Add the unique constraint
ALTER TABLE attendance 
ADD CONSTRAINT attendance_student_date_unique 
UNIQUE (student_id, date);

-- Verify it worked
SELECT constraint_name, constraint_type
FROM information_schema.table_constraints
WHERE table_name = 'attendance'
AND constraint_name = 'attendance_student_date_unique';
3 Click "RUN" (or press Cmd/Ctrl + Enter)

You should see a result showing the constraint was created.

✅ After running the SQL:
  1. Refresh your browser (F5)
  2. Go to Attendance Marking
  3. Mark some students
  4. Click "Save Attendance"
  5. See success message! 🎉
What this does: Ensures each student can only have one attendance record per day. If you mark attendance twice, it updates instead of creating duplicates.
