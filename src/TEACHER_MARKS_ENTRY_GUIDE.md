# 📝 MARKS ENTRY - TEACHER QUICK GUIDE

## ✅ GOOD NEWS: You Can Enter Decimal Marks!

The system now **automatically rounds** decimal marks to the nearest whole number.

---

## 📊 HOW ROUNDING WORKS

### Simple Rule: Normal Math Rounding

| You Enter | System Saves | Why? |
|-----------|--------------|------|
| 17.5      | **18**       | 0.5 rounds UP |
| 17.4      | **17**       | 0.4 rounds DOWN |
| 18.6      | **19**       | 0.6 rounds UP |
| 15        | **15**       | No decimal, no change |
| 20.0      | **20**       | .0 is same as whole number |

**Rounding Rule:**
- **Less than 0.5** → Round DOWN (17.4 → 17)
- **0.5 or more** → Round UP (17.5 → 18)

---

## 💡 WHAT YOU'LL SEE

### When You Enter Decimals

1. **Type your marks** (17.5, 18.3, etc.)
2. **Click "Save as Draft" or "Submit for Approval"**
3. **Blue notification appears:**
   ```
   📊 Decimal marks rounded to nearest whole number 
   (e.g., 17.5 → 18)
   ```
4. **Success message:**
   ```
   ✅ Marks saved successfully
   ```

### When You Enter Whole Numbers

1. **Type your marks** (17, 18, 19, etc.)
2. **Click "Save as Draft" or "Submit for Approval"**
3. **Success message only:**
   ```
   ✅ Marks saved successfully
   ```
   (No rounding notification - nothing was rounded)

## ❓ FREQUENTLY ASKED QUESTIONS

### Q: Can I still enter decimals?
**A: Yes!** Enter decimals naturally. The system will round them automatically.

### Q: Will 17.5 become 17 or 18?
**A: It becomes 18.** Standard math rounding: 0.5 rounds UP.

### Q: What if I enter 17.4?
**A: It becomes 17.** Less than 0.5 rounds DOWN.

### Q: Will I see the rounded values?
**A: Yes.** After saving, the table shows the rounded (whole number) marks.

### Q: Can I enter very precise decimals like 17.555?
**A: Yes.** But it will be rounded to the nearest whole number (18).

### Q: What about negative marks?
**A: Not allowed.** The system only accepts marks from 0 to the maximum for that assessment.

### Q: Does this affect my grading?
**A: Minimal impact.** Most Nigerian schools use whole numbers anyway. Rounding keeps it standard.

### Q: What if I disagree with the rounding?
**A: Just adjust before saving.** If you want 17 instead of 18, enter 17 directly (not 17.5).

### ✅ DO:

1. **Click "Edit" button** (only if status allows editing)

3. **Save again** - rounding applies again if you enter decimals

## 📞 NEED HELP?

  - CA1/CA2: 0-20 only
  - Midterm Exam: 0-20 only

- **Try a whole number:** If 17.5 doesn't work, try 18
