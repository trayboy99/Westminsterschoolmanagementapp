ERROR FIXED:
❌ column cbt_student_answers.points_earned does not exist
Teachers couldn't see student CBT answers due to database schema mismatch

ROOT CAUSE:
Backend was querying for `points_earned` column that doesn't exist
in the cbt_student_answers table.

ACTUAL COLUMNS in cbt_student_answers:
✅ id
✅ attempt_id
✅ question_id
✅ student_answer
✅ is_correct
✅ created_at
❌ points_earned (DOES NOT EXIST!)

SOLUTION APPLIED:
1. Removed `points_earned` from SELECT query
2. Calculate points_earned on-the-fly:
   - If is_correct = true → points = question.marks
   - If is_correct = false → points = 0

```typescript
// ❌ BEFORE: Querying non-existent column
.select(`
  question_id,
  student_answer,
  is_correct,
  points_earned  // ← DOESN'T EXIST!
`)

// ✅ AFTER: Query only existing columns
.select(`
  question_id,
  student_answer,
  is_correct
`)

// Calculate points earned dynamically
const pointsEarned = answer.is_correct ? question.marks : 0;
```
